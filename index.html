what is this

(skip this part if you want to)

enclave messenger is the first piece of project enclave — a hobby project started because i live in Manipur, India, where internet shutdowns are real. whatsapp, upi, telegram all go down when central servers can't be reached.

that's stupid design. trying something different.

goal: a messenger that doesn't die when one server goes offline. finds peers directly — internet, LAN, bluetooth, lora radio. whatever works.

how it works (roughly)

transport layer
  ├── internet      → raw DHT (kademlia-based, no central tracker)
  ├── local network → nmap-style peer discovery
  ├── sms           → via local or cloud sms api
  ├── bluetooth     → arduino / esp32 / device api
  └── lora          → arduino / esp32 (long range, low bandwidth)

identity layer
  ├── ed25519 keypair  → who you are (signing)
  └── x25519 prekeys  → session start (key exchange)

crypto layer
  └── noise protocol + double ratchet → e2e encryption

ui
  ├── flutter → desktop + android
  └── python bridge → web ui

no accounts. no servers. identity = keypair on your device. user id from public key. nobody can take it.
